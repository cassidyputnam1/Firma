GRIFFHORN PUTNAM WEBSITE

The original background video is already installed.

FONT: The entire page is configured to use Cossette Titre. The font itself is not included because a licensed font file was not provided. Add your licensed Cossette Titre web font named cossette-titre.woff2 into this folder, next to index.html. Until you add it, your browser will show a fallback font. If your file is .otf or .ttf instead, ask ChatGPT to adjust the code or export a properly licensed .woff2 for web use.

BANNER: GRIFFHORN PUTNAM repeats and continuously travels left to right. To adjust the motion speed, find 27s in index.html and change it (larger = slower).

EDIT LINKS: In index.html replace hello@example.com and yourusername, and edit Creative practice / Los Angeles.
